# 厦门大学附属第一医院成为“恒星计划——守护早产微宝贝”公益项目合作医院

> 更新时间：2026-09-11 (UTC+8)

近日，厦门大学附属第一医院与福建省恒申慈善基金会正式达成合作，共同启动“恒星计划——守护早产微宝贝”公益项目。该项目旨在为福建省内的早产儿及其家庭提供全面、专业的医疗救助与人文关怀服务，标志着厦门大学附属第一医院在早产儿综合救助与社会公益支持网络构建方面迈出更加坚实一步。

**项目介绍**

Project Description

“恒星计划——守护早产微宝贝”公益项目由福建省恒申慈善基金会发起，并获得北京春苗慈善基金会的专项支持。项目聚焦早产儿群体，致力于通过资源整合、技术赋能与服务探索三大核心举措，协助本地医疗机构及社会组织构建更完善、更可持续的早产儿救助服务体系。项目将不仅为符合救助条件的早产儿提供及时的医疗费用援助，减轻其家庭的经济负担，更将引入专业医务社工服务，为早产儿家庭提供贯穿治疗与康复过程的心理支持、养育指导与能力建设，着力缓解家庭在照护过程中面临的精神压力与养育困惑，从而提升早产儿家庭的整体应对能力与信心，努力减少因非医疗因素导致的治疗中断现象。

**救助范围**

Coverage of Assistance

在厦门大学附属第一医院内就医的，存在治疗费用不足的困难家庭早产儿（不限户籍），**满足以下其中一个条件即可申请救助**：

- 
孕周≤32 周，未出过院且求助申请时仍需持续住院治疗；

- 
孕周 32⁺¹～34⁰周（超过 32 周但未满 34 周），且出生体重≤1500 克，未出过院且求助申请时仍需持续住院治疗；

- 
早产儿出生后一年内，因早产相关并发症反复住院手术治疗的坏死性小肠结肠炎（NEC），此类患儿需开诊断证明，需写清病情诊断、预计住院时长、预计治疗费用及预后效果。

**救助标准**

Assistance Standards

**每位早产儿救助约5,000-50,000元**，依据家庭经济情况及治疗费用缺口情况综合考量救助额度，并且救助金额不高出出院发票中的“个人现金支付”部分。

**恒星计划**

厦门大学附属第一医院始终坚持以患者为中心，积极履行社会责任，关爱每一个脆弱的新生命。此次与福建省恒申慈善基金会的合作，是医院整合社会公益资源、拓展医疗服务内涵、提升人文关怀品质的重要实践。医院将充分发挥在新生儿危急重症救治方面的专业优势，特别是依托早产儿相关科室的雄厚技术力量，与基金会紧密协作，确保公益资源精准、高效地服务于确有需要的早产儿家庭，共同为这些“早到的天使”筑牢生命健康防线。
